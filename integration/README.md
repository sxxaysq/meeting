# 当前集成入口

项目主链路是 M1 抽取 → M3 项目身份与语义历史检索 → M6 生命周期管理。当前实现保留在 `m3_semantic_memory_20260917/candidate/`，批处理入口是该目录内的 `integration/m6_service/native_full_dataset.py`。详见该入口目录的 README。

- `m1_service/`：文件上传与 M1 九字段抽取。
- `m1_staging/`：M1 输出的严格校验、贴源入库和幂等扫描。
- `m1_web/`：M1 独立抽取面板。
- `m4_bidding/`：招投标分类及贴源结果服务。
- `m3_semantic_memory_20260917/export_semantic_demo.py`：只读导出当前语义回放的已完成会议到新的展示数据库。

上述独立服务与 M1 面板不代表已经统一的上传、生命周期处理和人工复核产品入口。本次清理保留源码功能，没有修改服务器部署、业务数据库或运行数据；线上状态需要另行验证。

历史中台编排、服务及批次入口已移除。请使用当前批处理的显式输入、部门配置和全新输出目录。
